# Пульт лампы (LampRemote)

Android-приложение, которое записывает BLE-пакеты пульта лампы и повторяет их с телефона.

## Как устроено
- Пульт не подключается к лампе, а шлёт пачку BLE-рекламы (legacy, non-connectable) с manufacturer data под Company ID `0xFFFF`.
- **Запись:** приложение сканирует эфир, берёт пакеты с `0xFFFF` и RSSI сильнее −70 dBm и группирует их в «пачки» (одно нажатие = одна пачка).
- **Отправка:** тот же payload передаётся с телефона ~0,7 с через `AdvertisingSet` (legacy, non-connectable, минимальный интервал 100 мс).
- Кнопки хранятся в SharedPreferences; «Экспорт»/«Импорт» — через буфер обмена в JSON.

## Сборка
GitHub Actions собирает `app-debug.apk` на каждый push (вкладка Actions → последний запуск → Artifacts).
Подпись — фиксированный debug-ключ `app/debug.keystore`, поэтому новые сборки ставятся поверх старых без потери кнопок.

Версии: AGP 8.5.2, Kotlin 2.0.20, Gradle 8.9, Compose BOM 2024.09.00, minSdk 31.

## Что проверить в первую очередь
1. Одинаковые ли пакеты у одной кнопки при повторных нажатиях (карточка пачки пишет «совпадает с пачкой #…»).
2. Реагирует ли лампа на «Отправить».
3. Реагирует ли она на **повтор** той же сохранённой кнопки (если в пакете есть счётчик, лампа может игнорировать повторы).
